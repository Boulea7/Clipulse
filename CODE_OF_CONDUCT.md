# Code of Conduct

## Our Standard

We want Clipulse to be a respectful, practical, and welcoming open-source project.

Examples of positive behavior:
- being respectful in technical disagreement
- giving actionable feedback
- assuming good intent
- focusing on the problem, not the person

Examples of unacceptable behavior:
- harassment or intimidation
- insulting or demeaning language
- bad-faith review behavior
- publishing private information without permission

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, pull requests, and other contributions that violate this code of conduct.

## Reporting

Please report serious issues through the security or maintainer contact path documented in `SECURITY.md`.
