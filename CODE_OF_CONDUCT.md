# Code of Conduct

## Our Standard

Clipulse should stay respectful, practical, and welcoming.

Examples of positive behavior:

- being respectful in technical disagreement
- giving specific, actionable feedback
- assuming good intent while still challenging ideas on the merits
- keeping public threads focused on the problem being solved

Examples of unacceptable behavior:

- harassment, intimidation, or stalking
- insulting, demeaning, or discriminatory language
- bad-faith review behavior or deliberate derailment
- publishing private information without permission

## Enforcement

Project maintainers may edit, hide, lock, or remove comments, issues, pull requests, and other contributions that violate this code of conduct.

## Reporting

- If the report includes private information, safety concerns, harassment details, or anything else that should stay non-public, use the private path in `SECURITY.md`.
- If you are unsure where to file something, start with `SUPPORT.md` and choose the narrowest path that keeps people safe.
- For ordinary moderation or collaboration concerns that can stay public, use the repository issue chooser and reference this code of conduct.
