# Security Policy

## Supported Scope

Clipulse is in active development. Security reports are welcome for:
- local adapters and hook/plugin integrations
- API authentication or request validation issues
- path leakage, prompt leakage, or source-content leakage
- dashboard or badge endpoints exposing unintended data

## Reporting

Please do not open a public issue for sensitive vulnerabilities.

Use one of these paths instead:
- GitHub private security advisory, if enabled
- direct maintainer contact through repository security channels

## Privacy Expectations

Clipulse is designed to avoid uploading:
- source file contents
- raw prompt contents

Any change that weakens those defaults must be explicitly documented and gated by user configuration.
